Quality and scope

    The data covers police-reported casualty crashes. The snapshot includes only six months of 2025, so that year is excluded. Later source revisions mean these records may differ from those available to analysts at the time.

    The source's Gold Coast classification can differ from the current boundary. The evaluation includes every serious crash with coordinates that the source assigns to the Gold Coast.

    A rejected uncertainty model

    Smoothing each count with the same prior leaves the ranking unchanged.

    AI and platform status

    Four read-only tools use MCP (Model Context Protocol) to return data and search documents. A live AI model is still pending. The Power BI report and BigQuery spatial queries were checked against this data snapshot.

    Method, reproducibility and sources

    GDA2020 coordinates are transformed into MGA zone 56 for metre-based distances. A 500 m grid uses a fixed origin independent of crashes. DBSCAN uses validation-selected 250 m neighbourhoods and five minimum points; this does not limit cluster diameter.

    Traffic volumes are not included, so the counts cannot measure risk per trip. Choosing a road treatment would also require an engineering assessment; this study does not estimate causes or crash reductions.
