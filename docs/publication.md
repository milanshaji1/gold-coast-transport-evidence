# Public release scope

This repository is a curated public copy of the local project at commit `fc1cfaac35dcabfda1e81bab0ecf51ec1a717a81`. Its initial public commit starts a new history so internal account records and application notes are not exposed through old revisions. References to earlier hashes in evaluation notes identify the retained local history, not commits in this public repository.

The Python implementation, dependency lock, original analytical freeze/results, MCP evaluation evidence and seven dashboard data exports are unchanged. The public preparation changes presentation links, deployment configuration and documentation. BigQuery SQL uses `YOUR_PROJECT_ID` in place of the original account identifier. Public platform records omit account/job identifiers but preserve execution results. Private account screenshots, browser-permission notes and job-application drafts are excluded.

The source data and its frozen release retain the Queensland Government CC BY 4.0 attribution. This independent project is not endorsed by the City or TMR. No live LLM endpoint is deployed. Contributions and known limitations are described in the README and contribution record.

A GitHub Pages workflow tests the Python fixtures and JavaScript metrics before deploying only `site/`. The account repositories and local analytical workspace are separate copies. Future analytical changes need a new evaluation and release; editing dashboard text does not change the frozen findings.
